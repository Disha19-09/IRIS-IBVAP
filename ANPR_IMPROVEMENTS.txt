┌───────────────────────────────────────────────────────────────┐
│  How It Works                                                  │
└───────────────────────────────────────────────────────────────┘

Vehicle Crosses Fence
  ↓
Crop vehicle from original quality frame
  ↓
Localize plate region (bottom 50% of vehicle)
  ↓
Enhanced preprocessing:
  • Convert to grayscale
  • CLAHE contrast enhancement (3.0)
  • Sharpen with kernel
  • Adaptive threshold → Binary image
  ↓
EasyOCR reads text
  ↓
Sanitize & validate:
  • Remove special characters
  • Match pattern: 2 letters + 5 digits
  • Format as "AA 82548"
  ↓
Check if plate already recorded
  ↓
If NEW: Save to database
If DUPLICATE: Skip (log only)

┌───────────────────────────────────────────────────────────────┐
│  Plate Format Patterns Recognized                             │
└───────────────────────────────────────────────────────────────┘

Primary Format (Strict):
  • 2 letters + 5 digits
  • Examples: AA82548, AA34261, AA34086
  • Formatted output: "AA 82548"

Fallback Format (Relaxed):
  • At least 5 characters
  • Must have both letters AND digits
  • Examples: ABC123, XY12345, etc.
  • Raw output: "ABC123"

Invalid (Rejected):
  • Less than 5 characters
  • Only letters or only digits
  • Too much noise/special characters
