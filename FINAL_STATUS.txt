🐛 TROUBLESHOOTING

If services won't start:
  1. Run STOP_ALL.bat
  2. Wait 5 seconds
  3. Run START.bat again

If a window closes immediately:
  • Check that window for error message
  • Ensure venv/ exists
  • Ensure node_modules/ exists

If no video shows:
  • Check MediaMTX window for errors
  • Check FFmpeg window is encoding
  • Verify test_4.mp4 exists

If no alerts appear:
  • CV pipeline takes time to detect events
  • Check CV-Pipeline window for detections
  • Open browser console (F12) for WebSocket logs
